# 技术路线｜华西 CBCT CEJ 曲线预测（A1+A2 主线，先生成项目结构）

> 目标：先把项目“可跑通的结构”搭出来（数据流水线/训练/推理/评估/可视化/回贴），参数先用占位默认值，后续统一走配置文件调整。

---

## 0. 范围与约束
- 输入：CBCT 灰度体 A + 牙体分割体 B（已像素级对齐）
- 已验证：B 含牙位编号，可直接得到每颗牙实例掩码 T_t
- 输出：全口 3D 张量 Y ∈ {0,1,2}^{X×Y×Z}
  - 0 背景，1 牙体，2 CEJ 曲线体素（由热力图预测后抽线得到）
- 医学/QC/模型评估对照输出（Mandatory）：
  - `CEJ_medical_compare_full.nii.gz`（1牙体，2手工标点，3插值曲线）
  - `CEJ_qc_compare_full.nii.gz`（1牙体，2插值曲线，3伪GT骨架）
  - `CEJ_model_compare_full.nii.gz`（1牙体，2插值曲线，3推理曲线）
  - `export_meta.json`（segment 定义 + 体素统计 + 一致性指标）

---

## 1. 总体策略（固定）
### A1｜强制单牙 3D ROI（训练/推理一致）
- 样本单位 = “一颗牙一个 ROI”
- ROI = bbox(T_t) 外扩 padding 后裁剪 A_t/T_t
- 记录 ROI↔原图映射，用于回贴生成全口 Y

### A2｜稀疏点 → 连续曲线伪真值 → 高斯管热力图监督
- 先拟合/插值生成连续曲线 C_t
- 稠密采样得到 P'_t
- 由 P'_t 生成 H_GT_t（高斯管热力图）作为监督目标

---

## 2. 数据接口定义（建议以 NIfTI/NPY 为落盘格式，接口不绑定具体格式）
### 2.1 Case 输入
- A: 3D 灰度（float32）
- B: 3D label（int16/int32）
- Meta（必须可读）：spacing / affine（或等价信息）
- **坐标统一约定**：以 `A.nii.gz` 的 `sform/qform`（affine）定义的世界坐标系为准，所有外部标注坐标需先对齐到该世界坐标系，再转换到体素坐标。

支持两种 raw 组织方式（由 `data.raw_layout` 控制，`auto` 自动判别）：
- `case_dirs`：`{raw_dir}/{case_id}/A.nii.gz + B.nii.gz (+ points/meta)`
- `toothfairy3`：`{raw_dir}/imagesTr/*_0000.nii.gz` + `{raw_dir}/labelsTr/{case_id}.nii.gz`
  - 可选：`pointsTr/{case_id}.json`
  - 可选：`meta_dir/{case_id}.json`

### 2.2 Tooth 实例
- 从 B 提取每颗牙实例掩码 T_t（binary）
- 牙位 id：tooth_id（例如 FDI 编码或数据自身编码）

### 2.3 标注输入
- 每颗牙 t 点集 P_t = {(x,y,z)}（默认体素索引；若物理坐标需提供映射）
- 点属于单牙 ROI 时需做坐标变换（全口→ROI）
- **注意**：若来自外部标注软件，坐标需先对齐到 `A.nii.gz` 的世界坐标系（由 affine 定义），再进行体素转换。

---

## 3. Pipeline（数据预处理 → 监督构造 → 训练/推理）

### 3.1 ROI 裁剪
步骤：
1) 取 T_t 的 bbox（xyz）
2) padding（单位 mm；通过 spacing 换算为 voxel）
3) 裁剪得到：
   - A_t（灰度 ROI）
   - T_t_roi（mask ROI）
   - P_t_roi（点坐标转换到 ROI）
4) 保存映射信息：
   - roi_origin_in_full（xyz offset）
   - roi_shape
   - spacing/affine（用于 mm 距离）

输出落盘建议（每颗牙一个样本目录）：
- A_t.nii.gz / A_t.npy
- T_t.nii.gz / T_t.npy
- points.json
- roi_meta.json（offset、spacing、affine等）

### 3.2（可选）空间/强度标准化
- 重采样到 target spacing（占位默认：0.5mm isotropic）
- 强度归一化（percentile clip + z-score 或 min-max）

### 3.3 稀疏点 → 连续曲线伪真值（Pseudo-GT）
最小可用实现（可插拔）：
1) 清洗：去离群点（阈值/统计规则）
2) 排序/连线策略（配置项）：
   - 按 z 分组
   - slice 内按角度/最近邻排序
   - 跨层用最近邻连接
3) 平滑拟合：cubic spline / B-spline
4) 稠密采样：步长 ds（占位默认：0.2mm）

输出：
- curve_dense_points.npy（P'_t）
- curve_vis.json（可视化用）

### 3.4 生成监督热力图 H_GT_t（高斯管）
- σ（占位默认：1.0mm）
- H_GT_t(v) = max_{p in P'_t} exp(-||v-p||^2/(2σ^2))

输出：
- H_GT.nii.gz / H_GT.npy

---

## 4. 模型与训练（MVP）
### 4.1 网络
- 3D U-Net / Res-UNet（实现不限定框架）
- 输入通道：
  - 最小：A_t（1ch）
  - 可选：concat(T_t_roi)（2ch）
- 输出：Ĥ_t（1ch，sigmoid）

### 4.2 损失
- 默认：Dice + BCE（热力图友好）
- 备选：Dice + MSE / Focal（配置项）

### 4.3 训练产物
- checkpoints/
- config.yaml（完整超参）
- train.log + metrics.csv
- 可视化抽检样例（固定数量/固定 case list）

---

## 5. 推理与后处理（MVP）
### 5.1 热力图 → 曲线体素
最小流程：
1) threshold：B̂_t = 1[Ĥ_t ≥ θ]（占位默认 θ=0.3）
2) 与牙体相交：B̂_t ← B̂_t ∩ T_t_roi
3) 抽线：
   - skeletonize 或轻量中心线提取
   - 保留最大连通主干
4) 得到 Ĉ_t（曲线体素，可选同步导出点集）

### 5.2 回贴到全口并生成 Y
- 在全口坐标系写入：
  - Y==1：牙体体素（来自 B/合并规则）
- Y==2：各牙的 Ĉ_t 回贴写入
- 输出：
  - Y_pred.nii.gz（或 npy）
  - per_tooth_curve_points/（可选）

### 5.3 伪GT链路一致性与导出门禁
默认链路是“处理一致”而非覆盖：
1) 手工点 -> 插值曲线（`curve_dense_points.npy`）
2) 插值曲线 -> `H_GT`（连续栅格化 + 高斯管）
3) `H_GT` -> 伪GT骨架（heatmap peak 抽取）

导出阶段自动计算 `C_interp` 与 `C_skeleton` 的重叠指标：
- `IoU >= 0.95`
- `Dice >= 0.97`
- 任一牙位不达标时，导出命令返回非零（默认 fail-fast）。

Slicer 默认使用细曲线模式：
- `skeleton_tube_radius_mm=0.0`
- `interp_tube_radius_mm=0.0`
- `points_tube_radius_mm=0.0`
- `nonoverlap_tubes_for_slicer=false`

---

## 6. 评估（按 PRD 指标）
### 6.1 Point-to-Curve Distance
- 对每个 GT 点 p（mm 距离）：
  d(p, Ĉ_t) = min_{c in Ĉ_t} dist_mm(p, c)
- 汇总：MeanDist、P95Dist（全点/分牙）

### 6.2 Success Rate @ τ
- SR@τ = (# {d ≤ τ}) / N
- τ 占位默认报告：0.5 / 1.0 / 1.5 mm

### 6.3 辅助指标（研发）
- 断裂段数量：连续 z 中无响应段数
- 层间漂移：相邻 z 曲线中心变化统计

输出：
- metrics_summary.json
- metrics_per_tooth.csv
- error_maps/（可视化）

---

## 7. 必须交付可视化（脚本化自动输出）
默认交付为 3D 交互可视化，2D 为可选抽检输出。
1) 3D 交互 viewer（默认）：`outputs/viz/3d/{case_id}/tooth_{tooth_id}/viewer.html`
   - MPR 三正交切片（axial/coronal/sagittal）
   - 牙体表面 mesh
   - GT/Pred 热图等值面
   - 预测曲线点云（默认红色 `#FF1744`）
   - 插值曲线 + 伪GT骨架对照
   - GT 点误差着色（mm）
   - 固定流程图例（`1 标注点` -> `2 插值曲线` -> `3 伪GT热图` -> `4 伪GT骨架` -> `5 推理热图` -> `6 推理曲线`）
2) 3D 索引页（默认）：`outputs/viz/3d/index.html`
3) 2D ROI 抽检（可选）：A_t + ∂T_t（多 slice）
4) 2D Pseudo-GT 抽检（可选）：稀疏点 + 拟合曲线 + H_GT
5) 2D 推理抽检（可选）：Ĥ_t + Ĉ_t（叠加在 A_t）
6) 2D 测试误差图（可选）：GT 点到 Ĉ_t 的距离分布

---

## 8. 配置（先占位，可在 config 中调整）
- ROI padding：`8mm`
- target spacing：`0.5mm` 各向同性
- 热力图 σ：`1.0mm`
- 稠密采样步长：`0.2mm`
- 抽线阈值 θ：`0.3`
- 评估容差 τ：`0.5 / 1.0 / 1.5 mm`
- 可视化：`viz.enable_3d=true`（默认），`viz.enable_2d=false`（默认，可选开启）
- 导出一致性阈值：`export_pseudo_gt.consistency_iou_min=0.95`，`export_pseudo_gt.consistency_dice_min=0.97`
- 一致性门禁开关：`export_pseudo_gt.fail_on_consistency_violation=true`
- Slicer 细曲线默认：`*_tube_radius_mm=0.0`
