# PRD｜华西项目：CBCT 釉牙骨质界（CEJ）曲线预测

## 1. 目标与范围
### 1.1 MVP 目标
给定每位患者的 CBCT 三维灰度体数据与对应牙体语义分割，自动预测 **CEJ（釉牙骨质界）空间曲线**，并输出与 CBCT 同尺寸的 3D 标注张量。

**关键策略（Mandatory）**：
- 训练与推理均以“单牙实例 ROI”为基本样本单位。每颗牙 `t` 对应一个裁剪后的 3D ROI（`A_t`、`T_t`、标注点 `P_t`）。
- 全口输出 `Y` 由各牙 ROI 推理结果回贴到原 CBCT 坐标系得到。

### 1.2 MVP 输出标签定义
输出张量 `Y ∈ {0,1,2}^{X×Y×Z}`：
- `0`：背景
- `1`：牙体（tooth）
- `2`：CEJ 曲线（由模型预测热力图后处理抽取得到的曲线体素）

### 1.3 医学核验导出（Slicer 对照文件）
除模型主输出 `Y` 外，MVP 还必须产出全口对照 NIfTI（单文件 0/1/2/3 标签）：

- `CEJ_medical_compare_full.nii.gz`
  - `1=牙齿本体`，`2=手工标点`，`3=伪GT插值曲线`
- `CEJ_qc_compare_full.nii.gz`
  - `1=牙齿本体`，`2=伪GT插值曲线`，`3=伪GT骨架`
- `CEJ_model_compare_full.nii.gz`
  - `1=牙齿本体`，`2=伪GT插值曲线`，`3=模型推理曲线`

配套产物：
- `export_meta.json`（segment 语义、体素统计、一致性指标）

### 1.4 非 MVP（Roadmap）
- 增加牙槽嵴顶（ABC）曲线、牙轴点、CEJ–ABC 距离展开 2D 图（本 PRD 不纳入验收）。

## 2. 输入数据规范
### 2.1 输入张量与元信息
对每个患者（case）提供：
- CBCT 灰度体 `A ∈ ℝ^{X×Y×Z}`，体素强度为灰度值
- 语义分割体 `B ∈ ℕ^{X×Y×Z}`，与 `A` **像素级对齐**（要求；如不对齐需先做配准/重采样对齐）
- 元信息（必须可读）：spacing / affine（或等价信息）
- **坐标统一约定**：以 `A.nii.gz` 的 `sform/qform`（affine）定义的世界坐标系为准，所有外部标注坐标需先对齐到该世界坐标系，再转换到体素坐标。

### 2.2 分割标签约定与预处理
`B` 的标签体系（现有约定）：
- 一位数：牙骨（alveolar bone）
- 两位数：牙体（tooth）
- 三位数：牙髓（pulp）

MVP 预处理：
- 合并牙髓→牙体：将牙髓标签映射到牙体标签集合 (`label % 100`)
- 构造二值牙体掩码 `T(x,y,z) = 1[B(x,y,z) ∈ ToothLabels]`，否则为 0

### 2.3 每颗牙 ROI / 实例掩码（已验证）
CEJ 是“每颗牙”概念，需得到每颗牙的实例掩码 `T_t`：
- `T_t(x,y,z) ∈ {0,1}` 表示牙 `t` 的体素集合
- ✅ `B` 已含牙位编号，可直接得到每颗牙实例掩码 `T_t`

### 2.4 ROI 裁剪与回贴定义（Mandatory）
- **ROI 定义**：以 `T_t` 的 3D bounding box 为中心，外扩 padding（单位 mm 或 voxel，建议 mm），裁剪得到 `A_t`、`T_t`、`P_t`（映射到 ROI 内坐标）。
- **回贴定义**：记录 ROI 到原体数据的 offset/仿射映射，推理得到的 `Ĉ_t` 回贴写入全口张量 `Y==2`。

### 2.5 强度与空间标准化（推荐）
- 推荐将 `A_t` 重采样到目标 spacing（近各向同性），并做强度归一化（percentile clip + z-score 或 min-max）。
- 所有距离评估统一使用物理单位 mm 计算。

## 3. 检查与验收基准
### 3.1 标注形式
每颗牙 `t` 在每个 z 切片上标注若干点（稀疏点），不要求闭合曲线。

### 3.2 坐标系与准入检查 (Mandatory)
- **坐标系**：体素索引或物理坐标（必须提供 Affine）。
- **统一坐标基准**：以 `A.nii.gz` 的 `sform/qform`（affine）为真实坐标系基准。
- **对齐检查必须输出**：抽检若干 slice，叠加 `∂T_t` 与原始灰度 `A`，验证 `A` 与 `B` 像素级对齐。
- **点落位检查必须输出**：统计 GT 点到牙体表面 `∂T_t` 的距离分布（mm），超出阈值的点需要报警/剔除（阈值作为配置项）。

### 3.3 伪GT链路一致性门禁 (Mandatory)
禁止“覆盖式”伪一致；必须通过处理链路保证：

1. 手工点 `P_t` -> 插值曲线 `C_interp`
2. `C_interp` -> 高斯管热力图 `H_GT`
3. `H_GT` -> 骨架曲线 `C_skel`

并在导出阶段执行门禁：
- `IoU(C_interp, C_skel) >= 0.95`
- `Dice(C_interp, C_skel) >= 0.97`
- 任一牙位不达标，导出流程必须返回非零退出码并记录到 `export_meta.json`。

## 4. 训练监督目标：曲线拟合与高斯管
对每颗牙 `t` 的稀疏点集 `P_t`，不直接使用离散点，而是构造连续曲线伪真值 (Pseudo-GT)。

### 4.1 构造流程
1. **曲线拟合**：对稀疏点 `P_t` 进行样条插值或平滑拟合，得到连续空间曲线 `C_t`。
2. **稠密采样**：沿 `C_t` 以固定步长（默认 0.2mm）采样得到稠密点集 `P'_t`。
3. **高斯管热力图**：
   - `H_GT(v) = max_{p ∈ P'_t} exp(- d(v,p)^2 / (2σ^2))`，其中 `σ` 默认为 1.0mm。
4. **实现配置项**：点序/连线策略属于实现配置项（例如按 z 分组后在 slice 内排序，再跨层连接并平滑）。

推理阶段输出热力图 `Ĥ_t`，经阈值与抽线后得到曲线体素 `Ĉ_t`，并回贴生成最终 `Y`（`Y==2`）。

## 5. 规则先验 (Geometric Priors)
采用 **几何代理：CEJ 是牙颈最收窄的一圈**。

**约定**：`R_t` 不作为硬标签，也不强制进入训练损失；必须实现其可视化抽检。可选开关：推理后用 `R_t` 对 `Ĥ_t` 做 gating（`Ĥ_t ← Ĥ_t * R_t`）作为后处理实验项。

### 5.1 牙体截面面积序列
对牙 `t` 的实例掩码 `T_t`，定义每个 z 的截面面积（以体素计数或 mm²；推荐 mm²）：
- 体素计数面积：`S_t(z) = Σ_{x,y} T_t(x,y,z)`
- 若需 mm²：`S_t_mm2(z) = S_t(z) * s_x * s_y`（`s_x, s_y` 为 spacing）

### 5.2 “最收窄层” z* 的定义
在牙体存在的 z 集合 `Z_t = { z | S_t(z) > 0 }` 上，定义：
- `z*_t = argmin_{z ∈ Z_t} S_t(z)`

> 备注：若担心冠部噪声或根尖截断导致假最小值，可加入搜索窗口 `Z_t'`（例如排除两端各 q% slice），该窗口为可配置项。

### 5.3 牙体表面距离（用于“CEJ 在牙齿表面附近”的约束）
定义牙体表面集合 `∂T_t`（例如 `T_t` 的 3D 边界体素集）。
定义到表面的距离变换（以体素或 mm）：
- `D_t(v) = dist(v, ∂T_t)`

### 5.4 几何先验候选带 R_t(v)
用两部分组成：**层带约束** + **表面邻域约束**。
- 层带权重（围绕最收窄层）：`Rz_t(v) = exp( - (z(v) - z*_t)^2 / (2σ_z^2) )`
- 表面邻域权重（靠近牙体表面）：
  - `Rs_t(v) = 1[ D_t(v) ≤ δ_s ]`
  - 或连续形式：`Rs_t(v) = exp( - D_t(v)^2 / (2σ_s^2) )`

最终几何先验：
- `R_t(v) = Rz_t(v) * Rs_t(v) * T_t(v)`

全口先验（若输出不分牙）：
- `R(v) = max_t R_t(v)`

### 5.5（可选）灰度边缘权重（待确认）
在牙体表面邻域内计算灰度梯度幅值：
- `G(v) = ||∇A(v)||`

归一化到 `[0,1]`：
- `Ĝ(v) = (G(v) - min)/(max - min + ε)`（在 ROI 内统计）

可选加入：
- `R_t(v) ← R_t(v) * Ĝ(v)`

> 该项为可选配置；若 CBCT 噪声/伪影较大，可关闭。

## 6. 评估指标
### 6.1 核心指标
- **Point-to-Curve Distance**: GT 点到预测曲线 `Ĉ_t` 的最近距离（mm）。
  - `MeanDist`
  - `P95Dist`
- **Success Rate @ τ**: 误差小于 `τ` 的点比例 (`τ = 0.5, 1.0, 1.5 mm`)。

### 6.2 辅助指标
- 断裂段数量
- 层间漂移

---

## 7. 交付产物要求
所有可视化与评估必须脚本化自动生成，固定目录结构（case_id/tooth_id 维度），保证可复现抽检与回归对比。
1. **3D 交互可视化（默认）**: 每颗牙输出可交互 HTML viewer（MPR 三正交切片 + 牙体表面 + GT/Pred 热图 + 预测曲线 + GT 点误差着色），并提供索引页。
2. **对齐抽检（2D，可选）**: `A` + `∂T` 叠加图。
3. **规则先验抽检（2D，可选）**: `R_t` 热力图。
4. **预测抽检（2D，可选）**: `A` + `Ĥ` + `Ĉ` (预测曲线)。
5. **误差分布图**: GT 点颜色编码显示到 `Ĉ` 的距离（2D 或 3D）。
6. **评估报告**: CSV 包含 per-tooth 的指标明细，输出 MeanDist、P95Dist、SR@τ（多档）。
7. **Slicer 对照文件（Mandatory）**: 每个 case 输出 3 个 compare NIfTI + `export_meta.json`（见 1.3）。
8. **细曲线默认策略（Mandatory）**: Slicer 导出默认不加粗（tube 半径默认 0.0）。

---

## 8. 参数配置默认值
*可配置项，建议写入 config 文件*
- **ROI Padding**: `8.0 mm`
- **Target Spacing**: `0.5 mm` (Iso)
- **Heatmap Sigma**: `1.0 mm`
- **Dense Step**: `0.2 mm` (曲线采样)
- **抽线阈值 θ**: `0.3`
- **评估容差 τ**: `0.5 / 1.0 / 1.5 mm`
